# Otter Code documentation

Welcome to the **Otter Code** documentation. Otter Code is a fork of [Qwen Code](https://github.com/QwenLM/qwen-code) with Otter branding and the `otter` CLI. It is an agentic coding tool for the terminal.

**Repository:** [github.com/Heron11/otter-code](https://github.com/Heron11/otter-code) — install instructions and the one-line installer live in the [README](https://github.com/Heron11/otter-code/blob/main/README.md).
